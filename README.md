# FreeText 🌐

A modern social network where people can connect, share posts, discover content, and express themselves freely.

## ✨ Features

- 🏠 Home feed
- 📖 Stories
- 🔎 Search
- 🧭 Explore
- 💬 Messages interface
- 🔔 Notifications
- 👤 User profiles
- ❤️ Like posts
- 🔖 Save posts
- 📸 Create posts with images
- 🌙 Dark mode
- 📱 Responsive mobile design
- 💾 Local browser persistence

## 🛠️ Built With

- React
- TypeScript
- Vite
- Lucide React
- CSS

## 🚀 Run Locally

Install the dependencies:

```bash
npm install

Start the development server:

npm run dev

Build for production:

npm run build

☁️ Deploy

FreeText is configured for deployment on Vercel.

The project can be connected to a GitHub repository and deployed as a Vite application.
